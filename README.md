# Flashback Machine

**História do Brasil, sem negacionismo.**

Linha do tempo interativa com 80 marcos, de 1500 a 2023. Os acontecimentos ficam
posicionados pela distância real entre eles — séculos vazios ficam vazios — e cada
afirmação traz a sua fonte: 100 no total, sendo 18 documentos primários.

**[Abrir o site](https://biafranzoi.github.io/flashback-machine/)**

Sem anúncio, sem login, sem rastreador.

## Como é feito

Site estático: HTML, CSS e JavaScript, sem build e sem dependências.
O conteúdo vive em `dados.js` — é o único arquivo que se edita para
acrescentar marcos.

A nomenclatura e a interpretação seguem o que é corrente na historiografia
acadêmica brasileira. Quando a leitura de um episódio é disputada entre
historiadores, o marco diz o que está em jogo.

Os textos são escritos com apoio de IA. O critério editorial e a curadoria são
meus, e cada marco traz suas fontes para conferência.

## Apoiar

A contribuição paga a pesquisa, a verificação das fontes e os próximos países a
entrar na linha do tempo: <https://apoia.se/flashback-machine>
